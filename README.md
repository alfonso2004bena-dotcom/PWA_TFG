# PWA_TFG

Progressive Web Application developed as part of a Bachelor's Thesis (TFG) in Industrial Technologies Engineering at ETSEIB-UPC.

The application helps microentrepreneurs in vulnerable environments manage their 
daily operations — cash flow, inventory and sales — and calculates the hourly 
income generated by their work.
Two versions are available, adapted to different business profiles:

- **`con-stock/`** — for manufacturing and food/fast-sales profiles (includes inventory management).
- **`servicios/`** — for service-based profiles (no inventory management).

Live demo: https://alfonso2004bena-dotcom.github.io/PWA_TFG/
